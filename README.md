# UniCruise 🎓

**UniCruise** is a web-based university and academic program exploration platform prototype designed to help students discover programs and universities based on their academic background, interests, location, and educational goals.

The website presents a personalized university discovery experience where students can create an account, complete a **Personalized Program Fit Assessment**, explore program recommendations, view graduate success insights, and review community feedback. The project focuses on designing and demonstrating how an intelligent university recommendation platform could work through a structured and user-friendly web interface.

> **Note:** UniCruise is a markup-based website prototype created to demonstrate the platform's intended features, workflows, and user experience. The recommendation, assessment, and analytics functionalities are presented as part of the system concept rather than as a fully implemented production system.

## ✨ Features

### 🔐 User Authentication

* User sign-up and login interface
* Personalized user experience after authentication
* User dashboard for accessing the platform's features

### 📊 Personalized Program Fit Assessment

Before accessing personalized program recommendations, users complete an assessment based on their academic background and preferences.

The assessment considers information such as:

* High school average grade
* Location within Region III
* Field of interest
* Desired education level (e.g., Bachelor's, Master's)
* Academic grades
* NCAE results

The collected information serves as the basis for the platform's proposed program-matching process.

### 🎯 Intelligent University Recommendation

The platform presents a conceptual recommendation system that matches students with university programs based on their assessment results, academic profile, interests, and preferences.

### 🎓 Graduate Success Insights

Users can explore career and graduate-related information intended to provide insight into possible career paths after completing a particular academic program.

This feature allows students to better understand potential career outcomes associated with their chosen programs.

### ⭐ Community Standard Reviews

UniCruise includes a community review component where students can view and contribute feedback regarding universities and academic programs.

### 📱 Student Dashboard

The dashboard serves as the central area where authenticated users can access:

* Program recommendations
* Assessment results
* University and program information
* Graduate success insights
* Community reviews

### 🛠️ Admin Dashboard

An administrative interface provides tools for monitoring platform activity and managing user-generated content.

Administrators can view:

Registered and active users
Student reviews
Website activity
Audit logs

### 📋 Audit Log

The system includes an audit log interface designed to record and monitor activities performed within the platform, providing administrators with greater visibility into website usage and administrative actions.

## 🧭 Platform Workflow

The intended user flow of UniCruise is:

**Sign Up / Login → Dashboard → Personalized Program Fit Assessment → Academic & NCAE Information → Program Recommendations → Graduate Success Insights & Community Reviews**

The assessment acts as the primary entry point to the personalized recommendation experience.

## 🎯 Project Purpose

UniCruise was designed around the idea of making university and academic program exploration more personalized and informative for students. Rather than relying solely on general university information, the proposed platform considers a student's academic performance, interests, educational goals, and location to demonstrate how personalized recommendations could assist in the decision-making process.

The project also incorporates graduate career insights and community feedback to provide students with additional perspectives when exploring their potential academic paths.

## 🧩 Project Scope

UniCruise is primarily a **markup-based web prototype**. Its purpose is to demonstrate the proposed system's:

* User interface
* Navigation and workflow
* Assessment process
* Recommendation experience
* Dashboard design
* Graduate success information
* Community review functionality
* Administrative interface
* Audit log concept

The website serves as a visual and functional representation of the proposed UniCruise platform rather than a fully deployed recommendation or analytics system.
